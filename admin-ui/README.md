# SES Admin UI

Admin management interface for Self Evolving Skills, built with Vue 3 + Element Plus + Vite.

## Features

- User, role, department, menu management
- Team Skills management & model configuration
- Workflow evolution proposals & review
- Offline cache & operation queue sync

## Quick Start

```bash
# Install dependencies
npm install

# Start dev server
npm run dev

# Build for production
npm run build:prod
```

## Tech Stack

- Vue 3 + Vite 5
- Element Plus
- Pinia
- Vue Router
